COMO PUBLICAR O SITE

1. Abra o arquivo index.html e troque SEU_NUMERO pelo WhatsApp do responsável, somente com números e código do país.
   Exemplo: 5515999999999
2. Se quiser receber pelo PicPay, coloque o @/link oficial do PicPay do responsável na página, depois de conferir os dados.
3. Publique o index.html em um serviço de hospedagem de sites estáticos, como GitHub Pages.
4. Não coloque senha, CPF, código de segurança ou dados bancários no site.
5. Como o vendedor é menor de idade, pagamentos e contratação devem ser tratados com um responsável.
